# Parashari-Raman v1 sources

`parashari_raman_v1` uses a fixed, auditable sequence: natal chart factors,
relevant divisional chart, Vimshottari dasha, then transit and SAV as
corroboration. Its citations use the following identifiers.

- `BPHS-RS-1984`: *Brihat Parashara Hora Shastra*, translated by R. Santhanam,
  Ranjan Publications, 1984. The catalogue uses its bhava, lord, varga,
  Vimshottari, and Ashtakavarga material as the classical basis.
- `BVR-HTJH`: B. V. Raman, *How to Judge a Horoscope*, Volumes I and II,
  Motilal Banarsidass. The catalogue uses its house-by-house organisation.
- `PRV1`: Ascendant's concise, versioned implementation of the selected rules.

The catalogue names sources and rule identifiers; it does not reproduce book
text. A chart claim cites its saved artifact as well as the rule and source
that selected it.
