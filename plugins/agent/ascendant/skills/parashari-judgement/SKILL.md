# Evidence-grounded Parashari judgement

Read [`../../../AGENTS.md`](../../../AGENTS.md), the shared
[`../../shared/process.md`](../../shared/process.md),
[`../../shared/hierarchy.md`](../../shared/hierarchy.md),
[`../../shared/artifacts.md`](../../shared/artifacts.md), and
[`../../shared/sources.md`](../../shared/sources.md). For HTML, also read
[`../../shared/html-report.md`](../../shared/html-report.md).

Apply the shared process to a general question about a saved chart, the `--html`
mode, or any request that does not map to a specialist topic. When the question
maps to a topic, route it to the matching specialist skill instead: career,
education, health, finance, family, marriage, property,
relationship-compatibility, or daily-transit.

A general reading applies the shared hierarchy directly, using the material
natal promise, relevant varga, activation, and corroborating factors for the
question asked. It never fabricates a factor or a topic rule that a specialist
rubric would supply.
