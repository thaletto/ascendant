# Daily planetary movements

Before applying this skill, read [`../AGENTS.md`](../AGENTS.md).

Use this skill when a user asks what is happening in the sky now, what today may feel like, or how the next few days may unfold.

## What to review

1. Get the current movement chart for the user's saved birth details.
2. Pay closest attention to the Moon, Sun, Mercury, Venus, and Mars.
3. Note which birth-chart life areas they are moving through.
4. Compare the movement with the user's birth planets and current planetary period.
5. Focus on changes that are close enough in time to be useful.

## How to explain it

- Separate quick changes from longer background themes.
- Describe likely moods, conversations, energy levels, and practical choices.
- Give a start or end window when the chart data supports one.
- Frame the reading as guidance for planning, not certainty.
- Offer a short checklist for the next day or week.

## Output

Use these sections:

- **Today’s tone**
- **Areas of focus**
- **What may feel easier or harder**
- **Helpful choices for the next few days**
