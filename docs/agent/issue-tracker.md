# Issue tracker: Linear

Issues and PRDs for this repository live in Linear. Use the Linear integration
for issue operations and associate work with the Ascendant project.

## Conventions

- Create one Linear issue per spec or ticket.
- Read the complete issue body, comments, and labels before acting on it.
- Apply or remove labels in Linear.
- Close issues only when their acceptance criteria are satisfied.
- Do not treat pull requests as incoming requests for triage.

## Publishing

When a skill says to publish to the issue tracker, create a Linear issue.
When a skill says to fetch a ticket, read the Linear issue and its comments.

## Dependencies

Prefer Linear's native issue dependencies for blocking relationships. Create
issues in dependency order so each blocker can be referenced by its issue
identifier. If native dependencies are unavailable, record a `Blocked by`
section in each issue body.
