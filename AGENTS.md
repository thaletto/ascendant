## Agent skills

### Issue tracker

Issues and PRDs live in Linear. Pull requests are not a triage
request surface. See `docs/agent/issue-tracker.md`.

### Triage labels

Use `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and
`wontfix`. See `docs/agent/triage-labels.md`.

### Domain docs

This is a single-context repository using root `CONTEXT.md` and `.docs/adr/`.
See `docs/agent/domain.md`.
