## Agent skills

### Issue tracker

When work creates, reads, updates, triages, or links an issue or spec, use
Linear under the Ascendant project. See `docs/agents/issue-tracker.md`.

### Triage labels

When a workflow triages an incoming issue or changes its triage state, use
`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and
`wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Before exploring code for a feature, bug, architecture change, or output that
names domain concepts, read the root `CONTEXT.md` and relevant ADRs. This is a
single-context repository. See `docs/agents/domain.md`.
